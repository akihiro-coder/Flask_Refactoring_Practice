### プロジェクト全体のリファクタリング

リファクタリングの練習を通して、以下の技術のコンテンツを学ぶことを目的とする。

- 認証技術（JWT, OAuth）
- API設計（GraphQL, OpenAPI）
- クリーンアーキテクチャ
