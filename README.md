# LLMリファクタリング用のプロンプト

### リファクタリング練習の目的
以下の項目を学ぶことを目的とする。
- ORM（データベースの）最適化
- エラーハンドリング
- 関数への切り分け等のコード設計
- 可読性の高いコード設計
- 保守性の高いコード設計
- 拡張性の高いコード設計
- パフォーマンス最適化
- Flaskの設計, ベストプラクティス
- 認証技術（JWT, OAuth）
- API設計（GraphQL, OpenAPI）
- クリーンアーキテクチャ
