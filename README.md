# LLMリファクタリング用のプロンプト

### リファクタリング練習の目的
以下の項目を学ぶことを目的とする。
- ORM（データベースの）最適化
- エラーハンドリング
- 関数への切り分け等のコード設計
- 可読性の高いコード設計
- 保守性の高いコード設計
- 拡張性の高いコード設計
- パフォーマンス最適化
- Flaskの設計, ベストプラクティス
- 認証技術（JWT, OAuth）
- API設計（GraphQL, OpenAPI）
- クリーンアーキテクチャ


### 前提プロンプト
```
あなたは優秀なソフトウェアエンジニア（シニアエンジニア）です。私は実務で使える人材になりたいので、リファクタリングの練習に付き合ってください。
```
### リファクタリングコード生成プロンプト
```
flaskアプリケーションのコードをリファクタリングする練習がしたいです。
以下の目的を元に、リファクタリングが必要なflaskアプリケーションコードを書いてください。
ただし、この練習は実務で役立てたいので、コードはとても複雑で実践的なコードにしてください。
また、コードを実際に実行させて修正作業をしたいので、htmlファイルもflaskアプリケーションプロジェクト内に含めてください。

目的:
リファクタリングの練習を通して、以下の技術のコンテンツを学ぶことを目的とする。
- 認証認可技術
- webAPI設計
- ORM（データベースの）最適化
- エラーハンドリング
- 関数への切り分け等のコード設計
- 可読性の高いコーディング
- 保守性の高いコーディング
- パフォーマンス最適化
- Flaskの設計
- 認証技術（JWT, OAuth）
- API設計（GraphQL, OpenAPI）
- クリーンアーキテクチャ
```
